Overview

EV Battery Failure Classification

Decision support for EV Maintenance Specialists: search a battery record, run a binary failure classification against the deployed model, and record the maintenance assessment and recommendation that follows.

Find a battery record Run a classification

What this system does

The EV Battery Failure Classification system predicts whether an electric-vehicle battery is heading toward a Failure using a supervised model trained offline on operational battery data. The result is strictly binary — Failure or No Failure — there is no intermediate health tier. Three roles share the workflow: a Data Scientist trains and exports the model offline (notebook-based, UC-01–03), a Software Developer deploys and verifies it with command-line utilities (UC-04–05), and the EV Maintenance Specialist — the user of this web application — runs classifications against battery records and turns results into maintenance assessments and recommendations (UC-06–09). This mockup shows only the Specialist-facing web application.
